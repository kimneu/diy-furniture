# UX Stufe A «Erster Moment» – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein Freund öffnet Martylko am iPhone und hat nach 30 Sekunden ein fertiges Beispielmöbel mit Preis gesehen, ein Mass geändert, 3D und Preis haben reagiert – ohne Pflichtdialog, ohne Zoom, ohne dass der erste Wisch das Möbel dreht.

**Architecture:** Sieben Tasks, jeder für sich deploybar. T0 baut ein UI-Prüfskript auf Patchright (`tools/`, keine Root-Abhängigkeit), das für jeden weiteren Task die rote/grüne Prüfung liefert; A1 stellt den Standards Mode her; A2 setzt das Mobile-Native-Paket per CSS und Meta; A3 schrumpft den Kopf und verlegt Kennzahlen in eine Steckbrief-Zeile unter der Bühne; A4 streicht den Pflichtdialog und macht die Möbel-Wahl zum Sheet; A5 ordnet das Formular nach Nutzungshäufigkeit; A6 lässt die 3D-Schleife nur rendern, wenn etwas zu rendern ist. Logik, die prüfbar ist, wandert nach `konfig.js` und bekommt `node:test`-Tests; Oberfläche wird über `tools/ui-pruefung.mjs` geprüft.

**Tech Stack:** Vanilla HTML/CSS/JS ohne Build (klassische Scripts, CommonJS-Guard für Node), three.js r128 (CDN, unverändert), Node ≥ 18 `node --test`, Patchright (nur `tools/`), Python `http.server` als Testserver.

**Spec:** `docs/review/2026-10-02-ux-review.md` (Kapitel 5 Entscheide, 6 Richtung, 7 Stufenplan, 10 iPhone-Prüfliste). Befunde mit Belegen: `docs/review/2026-10-02-ux-befunde.md`. Stufe B als Umriss: `docs/superpowers/plans/2026-10-02-ux-stufe-b-umriss.md`.

  Init-Script (wird per `context.addInitScript(fehlerSammeln)` vor jedem Script der Seite in die Hauptwelt eingefügt):
  ```js
  function fehlerSammeln() {
    const f = window.__uiFehler = [];
    const orig = console.error.bind(console);
    console.error = (...a) => { f.push('console.error: ' + a.map(String).join(' ')); orig(...a); };
    addEventListener('error', e => f.push(e.target && e.target !== window
      ? 'nicht geladen: ' + (e.target.src || e.target.href)
      : 'Fehler: ' + e.message), true);
    addEventListener('unhandledrejection', e => f.push('Promise: ' + (e.reason && e.reason.message || e.reason)));
  }
  ```

  Die Methoden von `ctx`, die an Patchright hängen (`BASE = http://127.0.0.1:<port>`, `netzFehler` ist eine `WeakMap` Page → Liste):
  ```js
  async oeffne(page, hash = '', { erst = false, dunkel = false } = {}) {
    await page.emulateMedia({ colorScheme: dunkel ? 'dark' : 'light' });
    await page.goto(BASE + '/preise.js');   // anderes Dokument: das Ziel lädt danach sicher neu, auch bei gleichem Pfad
    if (erst) await page.evaluate(p => { for (const k of Object.keys(localStorage)) if (k.startsWith(p)) localStorage.removeItem(k); }, SPEICHER);
    netzFehler.get(page).length = 0;
    await page.goto(hash.startsWith('?') ? `${BASE}/${hash}` : `${BASE}/${hash ? '#' + hash : ''}`);
    await page.waitForSelector('form#cfg.ready', { state:'attached', timeout:15000 });
  },
  haupt: (page, fn, arg) => page.evaluate(fn, arg, undefined, false),
  fehler: async (page) => [...await page.evaluate(() => window.__uiFehler || ['Fehlersammler fehlt'], undefined, undefined, false), ...netzFehler.get(page)],
  ```

  Der Rest ist so festgelegt:
  - **Freier Port.** `freierPort()` → `Promise<number>`: `net.createServer().listen(0, '127.0.0.1')`, den Port lesen, den Server schliessen.
  - **Server.** `spawn('python3', ['-m', 'http.server', String(port), '--bind', '127.0.0.1'], { cwd:ROOT, stdio:'ignore' })`.
  - **Warten auf den Server.** `warteAuf(url)` versucht bis zu 50 Mal im Abstand von 100 ms `fetch(url)`, bis die Antwort `ok` ist. Sonst wirft die Funktion `Error('Server antwortet nicht: ' + url)`.
  - **Browser.** Einmal `chromium.launch({ channel:'chrome', headless:true, args:['--enable-unsafe-swiftshader'] })`. Ohne SwiftShader gibt es headless kein WebGL für three.js.
  - **Neue Seite.** `neueSeite(optionen)` macht `browser.newContext(optionen)`, dann `context.addInitScript(fehlerSammeln)` und `newPage()`. Sie legt eine leere Netzliste in `netzFehler` an. `page.on('response')` hängt `"<status> <url>"` an, wenn der Status ≥ 400 ist. `page.on('requestfailed')` hängt `"nicht erreichbar: <url>"` an. Beide überspringen URLs, die auf `/favicon.ico` enden. `handy`/`desktop` rufen `neueSeite` mit den Optionen aus «Interfaces» auf.
  - **Schleife über die ids.** Für jede id ein eigenes `ctx`. `pruefe` und `screenshot` (mit `mkdirSync(SHOTS, { recursive:true })`, `page.screenshot({ path: SHOTS + name + '.png', animations:'disabled' })`) wie in «Interfaces». Im `try` läuft die Prüfung. Im `catch` zählt die Ausnahme als FEHLT und wird mit `String(e?.message ?? e).split('\n')[0]` ausgegeben. Im `finally` werden alle `browser.contexts()` geschlossen.
  - **Aufräumen.** In einem äusseren `finally` schliesst `browser?.close()` den Browser und `server.kill()` beendet den Server. Danach kommt die Schlusszeile.
  - **Einstieg.** Nur wenn `import.meta.url === pathToFileURL(process.argv[1]).href`, setzt das Skript `process.exitCode = await main(ids.length ? ids : Object.keys(PRUEFUNGEN))`. So können Tests später `PRUEFUNGEN` importieren, ohne dass etwas startet.

- **Rendern auf Abruf statt Dauerschleife.** Ein Frame läuft nur, wenn ihn jemand anfordert. Er plant den nächsten nur ein, solange `controls.update()` `true` liefert oder Türen oder Explosion ihr Ziel noch nicht erreicht haben. In r128 liefert `update()` `true` und feuert `'change'`, solange sich die Kamera noch bewegt, auch beim Ausdämpfen. Bei Ruhe liefert es `false`. `enableDamping` bleibt an.
- **Animationen rasten ein.** Liegt der Abstand zum Ziel unter 1e-3, springt der Wert aufs Ziel. So endet die Schleife sicher, nach rund 55 Frames ab Klick.
- **`three.ok = true` kommt als letzte Zeile vor dem ersten `requestRender()`**, also nach `three.tick`, dem `'change'`-Listener und dem IntersectionObserver. Wirft vorher etwas, bleibt `three.ok` false und der `catch` greift.
- **`resize()` rendert synchron** mit `camera.lookAt(controls.target); renderer.render(scene, camera);`. Ohne das bleibt der Canvas nach `setSize` leer, wenn `userMoved` true ist, denn dann ruft niemand `fitCamera` und damit `requestRender`. Der erste `resize()`-Aufruf (1673) läuft vor `tick`. Darum darf `resize` `tick` nicht aufrufen (TDZ).

Sein Callback ruft nur `requestRender`/`stopRender` auf, kein `resize()`.** Den Wechsel von `display:none` auf sichtbar meldet schon der bestehende ResizeObserver (1673).
